# Gomceix themes

Gomceix restyles libadwaita through documented named colours. A theme is a
single JSON file; place it in `~/.local/share/gomceix/themes/` (the value of
`XDG_DATA_HOME` is honoured if set) and it appears in Settings ▸ Appearance
next time the launcher starts. Built-in themes live in
`gomceix/ui/themes/` (adwaita, aurora, ember, forest, midnight, obsidian, paper)
and user themes in `~/.local/share/gomceix/themes/` override built-ins with the
same `id`.

## JSON schema

```json
{
  "schema": 1,
  "id": "mytheme",
  "name": "My theme",
  "scheme": "dark",
  "colors": {
    "accent": "#5b8def",
    "window": "#14161c",
    "card": "#1d212b",
    "header": "#10121a",
    "sidebar": "#0f1117",
    "popover": "#1d212b",
    "fg": "#e8ebf2",
    "success": "#57c785",
    "warning": "#e5a50a",
    "error": "#f66151"
  },
  "shape": { "radius": 14, "spacing": 12 },
  "background": { "image": null, "blur": 0, "dim": 0.0 }
}
```

| Key | Type | Required | Allowed values / range | Default | What it does |
|-----|------|----------|------------------------|---------|--------------|
| `schema` | integer | yes | must be `1` | — | Format version; anything else is a hard error (`theme.py:70-71`) |
| `id` | string | yes | `^[a-z0-9][a-z0-9_-]{0,39}$` (1–40 chars) | — | Internal identifier; also the file-stem used for lookup (`theme.py:72-74`) |
| `name` | string | no | any, truncated to 60 chars | `id` | Display name shown in Settings |
| `scheme` | string | no | `light`, `dark`, `system` | `system` | Sets the Adw color scheme: `light`/`dark` force it, `system` follows the desktop (`theme.py:75-77`, `theme.py:226-228`) |
| `style` | string | no | `flat`, `glass`, `glow` | `flat` | Finish of the cards and tiles: `glass` makes them translucent with a border, `glow` adds an accent border and shadow, also on popovers (`theme.py:82-86`, `theme.py:200-209`); any other value warns and `flat` is used |
| `colors` | object | no | see colour tokens below | `{}` | Colour overrides; an empty object means "use the desktop defaults" |
| `shape.radius` | integer | no | 0–32 | 14 | Border radius for `.gx-hero` and `.gx-card` (`theme.py:95-102`, `theme.py:157`) |
| `shape.spacing` | integer | no | 4–32 | 12 | Page padding is `spacing * 2` px (`.gx-page`, `theme.py:158`) |
| `background` | object | no | see below | `{}` | Reserved; `blur` (0–40) and `dim` (0.0–1.0) are accepted and stored but not otherwise applied by `css_for` |

### Colour tokens

`colors` keys are validated against this fixed set (`theme.py:22-23`, `theme.py:84-86`);
unknown keys produce a warning and are ignored. Each token maps to one or more
libadwaita named colours as generated by `css_for` (`theme.py:123-159`):

| Token | libadwaita colour(s) overridden | Meaning |
|-------|--------------------------------|---------|
| `accent` | `accent_bg_color`, `accent_color`, `accent_fg_color` | Accent colour; foreground is auto-computed for contrast |
| `window` | `window_bg_color`, `view_bg_color` | Window / view background |
| `view` | `view_bg_color` | View background |
| `card` | `card_bg_color` | Card background (`gx-card`) |
| `header` | `headerbar_bg_color`, `headerbar_backdrop_color` | Header bar |
| `sidebar` | `sidebar_bg_color`, `sidebar_backdrop_color` | Sidebar |
| `popover` | `popover_bg_color` | Popover / menu background |
| `fg` | `window_fg_color`, `view_fg_color`, `card_fg_color`, `headerbar_fg_color`, `popover_fg_color`, `sidebar_fg_color` | Foreground text |
| `success` | `success_bg_color`, `success_color`, `success_fg_color` | Success surfaces |
| `warning` | `warning_bg_color`, `warning_color`, `warning_fg_color` | Warning surfaces |
| `error` | `error_bg_color`, `error_color`, `error_fg_color` | Error surfaces |

Every colour value must match `^#(?:[0-9a-fA-F]{3}\|[0-9a-fA-F]{6}\|[0-9a-fA-F]{8})$`
(`theme.py:19`, `theme.py:87`); 3-digit hex is accepted. For `accent`,
`success`, `warning`, `error` the `_fg_color` variant is derived automatically
from luminance (`theme.py:48-62`): black text on light colours, white on dark.

## What `scheme` does

In `ThemeManager.apply` (`theme.py:215-228`):
- `light` → `Adw.ColorScheme.FORCE_LIGHT`
- `dark` → `Adw.ColorScheme.FORCE_DARK`
- `system` → `Adw.ColorScheme.DEFAULT` (follows the desktop), unless the caller
  passes an explicit `system_scheme`.

If a theme sets `colors` but declares `scheme: "system"`, a warning is emitted
(`theme.py:91-92`) because colour overrides are meaningful only with a fixed
light/dark scheme. The built-in `adwaita` theme has no `colors` and
`scheme: "system"` (`gomceix/ui/themes/adwaita.json`).

## Invalid files — warnings, never a crash

Theme loading is defensive (`theme.py:65-111`, `theme.py:167-183`):

- A file that is not valid JSON, or that fails structural validation (bad
  `schema`, bad `id`, bad `scheme`), raises `ThemeError`. `discover()` catches
  it, records the message in `ThemeManager.problems`, and **skips the file** —
  the launcher keeps running (`theme.py:176-178`).
- Invalid individual values (unknown colour key, non-hex colour, out-of-range
  `shape.radius`/`shape.spacing`, bad `background.blur`/`dim`) produce a
  **warning** and are ignored; the default value is kept (`theme.py:85-102`,
  `theme.py:104-110`).
- All warnings surface in Settings ▸ Appearance under "Theme file problems"
  (`gomceix/ui/pages/settings.py:39-43`). A bad theme never crashes the
  launcher and never prevents other themes from loading.
- User themes are loaded after built-ins and override built-ins with the same
  `id`; later files in sorted order win (`theme.py:170-180`).

## Built-in themes (reference)

Read `gomceix/ui/themes/*.json` for working examples:

- `adwaita.json` — `scheme: "system"`, no colours (desktop defaults)
- `aurora.json` — dark, `glass`, radius 16, spacing 12
- `ember.json` — dark, `flat`, radius 16, spacing 12
- `forest.json` — dark, radius 18, spacing 12
- `midnight.json` — dark, radius 14, spacing 12
- `obsidian.json` — dark, `glow`, radius 16, spacing 12; the default theme
- `paper.json` — light, radius 10, spacing 12

## Copy-pasteable example

Save as `~/.local/share/gomceix/themes/ocean.json`:

```json
{
  "schema": 1,
  "id": "ocean",
  "name": "Ocean",
  "scheme": "dark",
  "colors": {
    "accent": "#2aa8e0",
    "window": "#0b1120",
    "card": "#121a2c",
    "header": "#090d16",
    "sidebar": "#0a0e18",
    "popover": "#121a2c",
    "fg": "#d7e3f4",
    "success": "#4ade80",
    "warning": "#fbbf24",
    "error": "#f87171"
  },
  "shape": { "radius": 16, "spacing": 12 }
}
```

Then choose "Ocean" in Settings ▸ Appearance ▸ Theme.

## Tips

- **Contrast:** pick `fg` so it contrasts with `window`/`card`, and keep
  `accent` saturated enough that the auto-computed `accent_fg_color` (black on
  light, white on dark) stays readable.
- **Light vs dark:** declare `scheme: "light"` for light colour schemes and
  `scheme: "dark"` for dark ones; use `"system"` only when you set no colours,
  otherwise the theme warns that colours may clash with the desktop scheme.
- **Radius/spacing:** keep `radius` between 8 and 20 and `spacing` between 8
  and 16 for a native look. A value outside 0–32 (radius) or 4–32 (spacing) is
  not clamped: it is ignored with a warning and the default (14, 12) is kept.
- **Not every key is required:** omit `colors` entirely for a theme that only
  changes `shape` or relies on the desktop; omit `shape` to keep the defaults
  (radius 14, spacing 12).
